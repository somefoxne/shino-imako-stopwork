# Hỗ trợ toàn bộ cú pháp tag tìm kiếm theo Danbooru Cheatsheet:
# (https://danbooru.donmai.us/wiki_pages/help:cheatsheet)
#
# Ví dụ tag Danbooru:
#   id:<số>            : Quét post cụ thể (vd: id:8000000)
#   pool:<số>          : Quét post trong pool (vd: pool:12345)
#   pool:any           : Quét tất cả post thuộc bất kỳ pool nào
#   has:pools          : Tương tự pool:any
#   user:<tên>         : Quét post do user uploader tải lên (vd: user:artist_name)
#   tag_name           : Quét post có chứa tag này (vd: hatsune_miku)
#   rating:s/g/q/e     : Quét theo rating (vd: rating:g)
#   ALL                : Quét bài viết mới tổng thể
#
# Dấu trừ (-) để loại trừ trực tiếp theo chuẩn Danbooru:
#   -user:<tên>        : Loại trừ uploader (vd: -user:spammer)
#   -tag_name          : Loại trừ bài viết có tag này (vd: -comic)
#   -pool:<số>         : Loại trừ bài viết trong pool đó
#
# Chỉ thị hành động của Bot:
#   action:all         : Áp dụng tất cả hệ thống luật (mặc định)
#   action:2tag        : Chỉ áp dụng hệ thống 2 tag
#   action:3tag        : Chỉ áp dụng hệ thống 3 tag
#
# Chỉ thị Thông báo & Hỏi duyệt (Noti:):
#   Noti:discord       : CHỈ gửi log thông báo kết quả cập nhật vào Discord (không hỏi)
#   Noti:ask           : CHỈ gửi câu hỏi duyệt bằng nút bấm (Đồng ý / Bỏ qua). Nếu được đồng ý mới thêm.
#   (Kết hợp cả 2: Hỏi duyệt trước, nếu đồng ý thì thêm và gửi log thông báo)
#
# Chỉ thị Kiểm soát sửa lại khi tag bị người khác xóa (readd:):
#   readd:never        : Nếu tag từng được bot thêm mà bị người khác xóa -> Không bao giờ add lại
#   readd:5            : Nếu tag bị xóa -> Chỉ add lại khi đã có ít nhất 5 lượt chỉnh sửa sau đó
#   (Mặc định lấy theo RE_ADD_POLICY trong file .env nếu không ghi)
#
# ------------------------------------------------------------------------------
