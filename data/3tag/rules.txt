# ==============================================================================
# HỆ THỐNG LUẬT 3 TAG & N-TAG (CÚ PHÁP MỚI)
# ==============================================================================
# 1. Dạng mũi tên (Implication):
#    A B C -> D <E>
#    - Có đủ A B C thì thêm D, trừ khi có tag E trong <E>
#
# 2. Dạng neo bắt buộc & suy luận tương hỗ (?):
#    ?A B C <E>
#    - ?A là tag bắt buộc phải có (và không bao giờ được thêm).
#    - Có A, B -> thêm C
#    - Có A, C -> thêm B
#    - Có B, C (thiếu A) -> không thêm gì
#
#    ?A B C D <E>
#    - ?A là bắt buộc phải có.
#    - Có 2 trong 3 {B, C, D} -> tự động bù tag thứ 3 còn thiếu.
#    - Nếu có tag trong <E> -> hủy bỏ qua.
#
#    ?A ?B C D E F G <H I K>
#    - Cần cả ?A và ?B. Thiếu 1 tag trong tập {C, D, E, F, G} -> tự động bù.
# ==============================================================================

# Ví dụ dạng mũi tên:
school_uniform sailor_collar pleated_skirt -> student <cosplay>

# Ví dụ dạng ?A B C (Cần ?twintails: có hair_ribbon thì bù twin_ribbons; có twin_ribbons thì bù hair_ribbon)
?twintails hair_ribbon twin_ribbons <single_ribbon>

# Ví dụ dạng ?A B C D:
?vampire fangs pointy_ears cape <elf>
